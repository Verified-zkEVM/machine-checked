# Refine

Layer 2 of the [roadmap](../../ROADMAP.md): specification refinement. **Not started**; this
directory has no code.

The plan is tools for refining a high-level specification (at the level of a mathematical
library of algorithms and protocols) down to the structured logical program
([`../Logical`](../Logical/README.md), layer 1). The program is lifted up to layer 1, the
specification is refined down to it, and the two meet there.

Today each case study connects its specification to its proofs directly (for example
`Cases/Zip2005/Spec`). The roadmap's first targets are what this layer will be designed
against. To contribute, open an issue first ([`CONTRIBUTING.md`](../../CONTRIBUTING.md)).
