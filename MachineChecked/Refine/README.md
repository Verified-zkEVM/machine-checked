# Refine

**Layer 2 of the [roadmap](../../ROADMAP.md): specification refinement. Not started.**

Tools for refining a high-level specification (at the level of a mathematical library of
algorithms and protocols) down toward the structured logical program (`../Logical`, layer 1).
A verification effort works from both ends: the program ascends through the lifts and the
program logics, the specification descends through refinement, and the two meet at layer 1.

Today each case study connects its specification to its proofs directly (for example
`Cases/Zip2005/Spec`). The first targets in the roadmap are what this layer is to be designed
against. Contributions are welcome: open an issue first (see
[`CONTRIBUTING.md`](../../CONTRIBUTING.md), "Larger contributions").
