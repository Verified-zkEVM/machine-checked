# Check

The contract checker, a layer-0 proof tool (see [`../README.md`](../README.md)). Given a
function's code, an untrusted annotation (a certificate) and its callees' interfaces,
`Domain.lean` computes a Boolean saying the function meets its own interface. The kernel
evaluates it, and the soundness theorems turn an accepted check into a statement over
riscv-zkvm's `stepSp1`. Results enter the contract table as `SafeN` facts.

Annotations and interfaces are generated by `Tools/Infer.lean`. The generator is not trusted;
the kernel checks its output.

## Main declarations

- `Iface` (`Domain.lean`): a function's interface: entry, premises over entry registers,
  footprint, stack bound, callee-saved registers, and return.
- `Iface.HoldsN` (`Spec.lean`): what an interface means, as `SafeN` in continuation form.
- `Ctx.sound`, `table_sound` (`Sound/Act.lean`): an accepted annotation makes the function
  meet its interface, provided its callees meet theirs for smaller budgets; a table of checked
  functions meets all its interfaces.

## Files

| file | contents |
| --- | --- |
| `Domain.lean` | The abstract domain, transfer functions and checker. |
| `Fact.lean` | Facts and certificates: linear inequalities, exact values, and the symbols the checker may know. |
| `Model.lean` | Typed resources: objects passed by pointer whose kind fixes a typing predicate over memory. |
| `Region.lean` | Address-space regions and their disjointness. |
| `Statics.lean` | Read-only data and protected statics stay as loaded. |
| `Ecall.lean` | What each system call does under `stepSp1`, in the form soundness needs. |
| `Arith.lean` | Address arithmetic for frame windows, footprints and store keys. |
| `Spec.lean` | The meaning of an interface. |
| `Sound.lean`, `Sound/` | Soundness, in five parts: the invariant (`Core`), knowledge (`Kn`), straight-line instructions (`Plain`), calls and returns (`Call`), the activation (`Act`). |
| `Fast.lean` | The one-pass check implies the indexed one. |
| `Image.lean` | Discharges the checker's code premise from a loaded image. |
