# Check

**A layer-0 proof tool** (see [`../README.md`](../README.md)): it proves things about
riscv-zkvm's machine directly, without the lift to Lprog. Its results enter the contract table
as `SafeN` facts.

The contract checker. From a function's code, an untrusted annotation (a certificate) and the
interfaces of its callees, `Domain.lean` computes a Boolean that says the function meets its
own interface. The kernel runs it. The soundness theorems turn an accepted check into a
statement over riscv-zkvm's `stepSp1`.

## Main declarations

- `Iface` (`Domain.lean`): a function's interface. It gives the entry, the premises over
  entry registers, the footprint, the stack bound, the callee-saved registers and the return.
- `Iface.HoldsN` (`Spec.lean`): what an interface means, as `SafeN` in continuation form.
- `Ctx.sound`, `table_sound` (`Sound/Act.lean`): an accepted annotation makes the function
  meet its interface, given its callees do for smaller budgets; a table of checked functions
  meets all its interfaces.

## Files

| file | contents |
| --- | --- |
| `Domain.lean` | The abstract domain, the transfer functions and the checker. |
| `Fact.lean` | Facts and certificates: linear inequalities, exact values and the symbols the checker may know. |
| `Model.lean` | Typed resources: objects handed by pointer whose kind fixes a typing predicate over memory. |
| `Region.lean` | Address-space regions and their disjointness. |
| `Statics.lean` | Read-only data and protected statics stay as loaded. |
| `Ecall.lean` | What each system call does under `stepSp1`, in the shape soundness needs. |
| `Arith.lean` | Address arithmetic for frame windows, footprints and store keys. |
| `Spec.lean` | The meaning of an interface. |
| `Sound.lean`, `Sound/` | Soundness, in five parts: the invariant (`Core`), knowledge (`Kn`), straight-line instructions (`Plain`), calls and returns (`Call`), the activation (`Act`). |
| `Fast.lean` | The one-pass check implies the indexed one. |
| `Image.lean` | The checker's code premise, discharged from a loaded image. |

Annotations and interfaces are generated by `Tools/Infer.lean` and checked by the kernel.
The generator is not trusted.
